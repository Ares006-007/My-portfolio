# Codebase Map

A breakdown of the project directory structure and key files.

## Root Directory (`/`)
- `docs/` - Auto-generated documentation about the system design, tech stack, and workflows.
- `public/` - Static assets (images, icons) served directly without Vite transformation.
- `src/` - The main application source code (React + Vite).
- `dist/` - The output directory for production builds (generated by `npm run build`).
- `firebase.json` / `.firebaserc` - Firebase configuration for hosting and deployment.
- `package.json` - Node dependencies and NPM scripts (`dev`, `build`, `preview`).
- `vite.config.js` - Vite bundler configuration.

## Application Source (`src/`)

### Main Entry Points
- `src/main.jsx` - The React application entry point. Bootstraps the app and wraps it in a Router.
- `src/App.jsx` - The root React component. Defines primary routing (`/`, `/books`, `/admin/login`, `/admin`) and global layout wrappers.
- `src/index.css` - The global design system. Contains core CSS variables, typography, and all major styling for both the public site and the Admin dashboard.

### `src/components/` (UI Components)
The building blocks of the application frontend.

**Public Components**
- `Hero.jsx` - Landing section of the homepage; fetches and conditionally displays the "Under Construction" banner.
- `About.jsx` - Displays biography and stats.
- `Projects.jsx` - Renders the portfolio projects grid.
- `Hackathons.jsx` - Renders a timeline of achievements and events.
- `Skills.jsx` - Displays skill categories.
- `Contact.jsx` - Renders the contact section and footer links.
- `Library.jsx` / `BooksPage.jsx` - Renders the "On My Shelf" book library fetched from the CMS.
- `MusicLibrary.jsx` / `MusicPage.jsx` - Renders the "Listening Archive" fetched via Spotify API or the CMS fallback.

**Utility & Animation Components**
- `AnimatedText.jsx` - Handles GSAP text-reveal animations.
- `RevealOnScroll.jsx` - Wrapper for triggering framer-motion animations on scroll.
- `CustomCursor.jsx` - Renders the custom interactive mouse cursor.
- `Ballpit.jsx` - The interactive physics-based background simulation on the Hero section.
- `SpotifyHelper.js` - Utility functions for normalizing Spotify data and building embedded players.

### `src/components/admin/` (CMS Dashboard)
The protected interface for editing site content.
- `AdminDashboard.jsx` - The main admin layout (sidebar + active panel).
- `ProtectedRoute.jsx` - A routing wrapper that redirects unauthenticated users to the login screen.
- `AdminLogin.jsx` - Authentication UI (Google Sign-In).
- `AdminAbout.jsx` - Edits global site config, bio, and the Under Construction banner.
- `AdminProjects.jsx` - CRUD interface for the `projects` collection.
- `AdminAchievements.jsx` - CRUD interface for the `achievements` collection.
- `AdminSkills.jsx` - CRUD interface for the `skills` collection.
- `AdminBooks.jsx` - CRUD interface for the `books` collection.
- `AdminLibrary.jsx` - CRUD interface for the `library` collection (Music).

### `src/data/` (Data Access Layer)
- `portfolioStore.js` - The single source of truth for database operations. Contains Firebase Firestore queries, CRUD helper functions, and default seed data arrays.

### `src/utils/` (Third-Party Integrations)
- `spotifyAuth.js` - Handles Spotify OAuth login, token refresh, and URL parsing.
- `spotifyApi.js` - Wraps HTTP requests to the Spotify Web API.

### `src/hooks/` (Custom React Hooks)
- `useAuth.js` - Custom hook for managing Firebase Authentication state and login/logout actions.
